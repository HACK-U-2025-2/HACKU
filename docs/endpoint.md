# API Documentation

## Base URL
http://localhost:8000

---

## メモ関係

### `GET /memos/`
- **説明**: メモ一覧を取得
- **リクエスト**:
    - **クエリパラメータ**:
        - `keyword`: 検索キーワード（省略可）
        - `tag_names`: タグ名のリスト（省略可）
        - `sort`: ソート方法（省略可）
        - `is_archive`: アーカイブのメモかどうか（省略可，その場合は全てのメモを取得）
    - **ヘッダ**:
        - `Authorization`: Bearer トークン（必須）
- **レスポンス**:
    - 200: メモ一覧（`[MemoPreviewResponse]`）
    - 401: 認証情報が不正
    - 422: リクエストが不正

---

### `GET /memos/{memo_id}`
- **説明**: 指定されたメモの詳細を取得
- **リクエスト**:
    - **パスパラメータ**:

    - **ヘッダ**:

### `POST /memos/`
- **説明**: 新たなメモを投稿。サーバ側で要約およびタイトルを自動生成。`校正フラグ` が有効なら要約前に校正。`タグ生成フラグ`が有効ならタグを自動で追加(tag_namesと競合しない)。
- **リクエスト**:
    - **ヘッダ**:
        - `Authorization`: Bearer トークン（必須）
    - **ボディ** (`MemoCreateRequest`):
        - `body`: 本文（必須）
        - `tag_names`: タグ名のリスト（必須）（タグを全て自動で決めたい際は空配列を渡す）
        - `need_proofreading`: 校正フラグ（必須）
        - `need_generate_tags`: タグ生成フラグ（必須）
- **レスポンス**:
    - 201: 作成されたメモ（`MemoResponse`）
    - 401: 認証情報が不正
    - 422: リクエストが不正

### `PUT /memos/{memo_id}`
- **説明**: メモの修正
- **リクエスト**:
    - **ヘッダ**:
        - 認証情報
    - **ボディ**:
        - メモ内容(必須)
        - メモタイトル(必須)
        - タグ一覧(必須)
- **レスポンス**: 
    - 200: Null
    - 401: ユーザ情報が不正
    - 404: メモが存在しない
    - 422: リクエストが不正

### `PATCH /memos/{memo_id}/body`
- **説明**: メモの文章修正(http版)
- **リクエスト**:
    - **パスパラメータ**:
        - `memo_id`: メモID（必須）
    - **ヘッダ**:
        - `Authorization`: Bearer トークン（必須）
    - **ボディ** (`MemoBodyUpdateRequest`):
        - `body`: 修正後の本文（必須）
- **レスポンス**:
    - 200: 正常に更新
    - 401: 認証情報が不正
    - 404: メモが存在しない
    - 422: リクエストが不正

## 認証関係

### `POST /auth/`
- **説明**: ユーザーIDをもとにアクセストークン（有効期限1日）を発行
- **リクエスト**:
    - **ボディ** (`AuthRequest`):
        - `user_id`: ユーザーID（必須）
- **レスポンス**:
    - 200: アクセストークン（`TokenResponse`）
    - 422: リクエストが不正
