# API Documentation

## Base URL
http://localhost:8000

## メモ関係
### 'GET /memos/'
- **説明**: メモ一覧を取得
- **リクエスト**:
    - **クエリパラメータ**:
        - 検索キーワード
        - 検索タグ
        - ソート方法
    - **ヘッダ**:
        - 認証情報
    - **ボディ**:
        - 
- **レスポンス**: 
    - 200: メモ一覧
    - 403: ユーザ情報が不正
    - 422: リクエストが不正


### 'GET /memos/{memo_id}'
- **説明**: 指定されたメモの詳細情報を取得，メモのidをパスパラメータで指定
- **リクエスト**:
    - **ヘッダ**:
        - 認証情報
    - **ボディ**:
- **レスポンス**: 
    - 200: メモ情報
    - 403: ユーザ情報が不正
    - 404: メモが存在しない

### 'POST /memos/'
- **説明**: 新たなメモを投稿、要約を(タイトルなしの場合はこれも)サーバ側で作成、校正フラグがtrueなら要約前にメモをサーバ側で校正
- **リクエスト**:
    - **ヘッダ**:
        - 認証情報
    - **ボディ**:
        - 校正フラグ(必須)
        - 要約前のメモ内容(必須)
        - タグ一覧
- **レスポンス**: 
    - 201: メモ情報
    - 403: ユーザ情報が不正
    - 422: リクエストが不正

### 'PUT /memos/{memo_id}/body'
- **説明**: メモの文章修正(http版)
- **リクエスト**:
    - **ヘッダ**:
        - 認証情報
    - **ボディ**:
        - メモタイトル
- **レスポンス**: 
    - 200: Null
    - 403: ユーザ情報が不正
    - 404: メモが存在しない
    - 422: リクエストが不正

### 'websocket /memos/{memo_id}/body'
- **説明**: メモの文章修正(websocket版)
- **リクエスト**:
    - **ヘッダ**:
        - 認証情報
    - **ボディ**:
        - メモ内容
- **レスポンス**: 
    - success: Null
    - unauthorized: ユーザ情報が不正
    - not_found: メモが存在しない
    - validation_error: リクエストが不正

### 'PUT /memos/{memo_id}/title'
- **説明**: メモのタイトル修正
- **リクエスト**:
    - **ヘッダ**:
        - 認証情報
    - **ボディ**:
        - メモタイトル
- **レスポンス**: 
    - 200: Null
    - 403: ユーザ情報が不正
    - 404: メモが存在しない
    - 422: リクエストが不正

### 'PUT /memos/{memo_id}/tag'
- **説明**: メモのタグ修正
- **リクエスト**:
    - **ヘッダ**:
        - 認証情報
    - **ボディ**:
        - タグ一覧
- **レスポンス**: 
    - 200: Null
    - 403: ユーザ情報が不正
    - 404: メモが存在しない
    - 422: リクエストが不正

### 'DELETE /memos/{memo_id}'
- **説明**: メモを削除
- **リクエスト**:
    - **ヘッダ**:
        - 認証情報
    - **ボディ**:
- **レスポンス**: 
    - 204: Null
    - 403: ユーザ情報が不正
    - 404: メモが存在しない

## タグ関係
### 'GET /tags'
- **説明**: ユーザが使用したタグ一覧を取得
- **リクエスト**:
    - **クエリパラメータ**:
        - 検索タグキーワード
    - **ヘッダ**:
        - 認証情報
    - **ボディ**:
- **レスポンス**: 
    - 200: タグ一覧
    - 403: ユーザ情報が不正
    - 422: リクエストが不正

### 補足
- タグはメモと紐つかない限りユーザに何も提供できないので、GET以外はフロントで使わない想定
- 代わりに、追加・編集・削除は'POST /memos/', 'PUT /memos/{memo_id}', 'DELETE /memos/{memo_id}'の内部アルゴリズムで行う
- あまりいい方法ではないの気がするのでコメント大歓迎
